# 春熙路旅行规划

核心功能是“旅行袋 + AI 行程整理”：先把真正想去的地方装进旅行袋，再让 AI 根据这些选择整理成一份春熙路路线参考。旅行袋用于规划行程，不下单、不支付。

## 项目核心思想

产品定位、体验原则和当前实现边界见 [项目核心思想](./项目核心思想.md)。

本次功能检查结果与验收范围见 [验收文档](./验收文档.md)。

## 运行

```sh
npm install
npm run dev
```

生产构建：

```sh
npm run build
```

## 当前说明

- React 18 + Tailwind CSS + Vite 单页演示，无路由、无后端。
- 包含 25 家地点，分为美食、玩、拍照打卡、活动、购物五类。
- 路线建议由本地演示逻辑生成，不调用在线 AI 服务；完成规划后旅行袋清空。
- 评分、示例评论、地图点位和参考花费用于演示，不代表实时点评数据、导航信息或实际价格。
- 用户发布的评论仅保存在当前浏览器本地。
